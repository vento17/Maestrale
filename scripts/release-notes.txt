0.4.1 — iControls widget, Enttec Open DMX fixed, DMX channels in the cell editor

- New iControls widget: an iCON iControls / iControls Pro in Mackie mode comes
  in as nine faders (eight plus master, touch-sensitive, 14-bit) and nine knobs
  (the eight V-Pots plus the jog wheel), each one a cell you can patch anywhere
- Enttec Open DMX: the FTDI driver now opens the dongle properly, so the
  universe actually goes out
- Cell editor: a slider, button or knob bank set to Enttec Open DMX now shows
  its DMX channel, like Art-Net and sACN already did — the column was missing
  altogether, so there was no way to set a channel by hand
- Cells added to a bank now follow the bank's protocol. Growing a DMX, OSC or
  sACN bank used to hand the new cells MIDI defaults
- Name: Maestrale throughout — window, README, repository and Release
