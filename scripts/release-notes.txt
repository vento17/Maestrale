0.4.2 - OSC scale, Eos faders from any bank, Math takes any number of cables, a name on every widget

- OSC value scale: a fader at full can send 1, 10 or 100, as a float or as a
  whole number. Range and Type sit in the Output protocol section for the whole
  bank, and per cell in Edit cells. TouchDesigner wants 0-1 floats, a desk
  0-100 ints, Resolume 0-100 - no more guessing
- Eos faders from ordinary sliders, knobs and buttons: with OSC on, an "Eos
  faders" section takes the desk number of the first fader (11 = page 2,
  position 1) and the OSC bank; every cell follows. The address
  /eos/fader/<bank>/<pos> and the bank config /eos/fader/<bank>/config/<page>/10
  are written for you, cell by cell, and stay editable. Eos listens to a bank
  only after that config, so it goes out by itself before the first level and
  again every few seconds while you move; a button sends it now. A button
  whose address is itself a config message sends it bare on press
- Math: like the Merge, a dashed box that takes as many cables as you like -
  Shift-drag onto it in Live and each cable becomes the next input. One cable
  alone passes straight through, two add up, and so on; add, subtract (in 1
  minus the rest), multiply, min, max, average, invert and abs work over all of
  them. Source A / B remain as the fallback for in 1 / in 2. A Multiply field
  scales the result after the ranges and the clamp: x100 sends 0-100
- Every widget has a thin edge, in Design and in Live, with its own colour and
  width. Show name widens the top edge into a title bar carrying the widget's
  name, in the font size you set - a Title & edge section on every widget
- Edit cells: changing an OSC address no longer wipes the cell's range, Eos
  user and output - the field used to rebuild the mapping from scratch
